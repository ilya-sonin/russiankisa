# Визуальный QA адаптива

Проверка от 11 октября 2026 года выполнена на статической production-сборке в Chromium: desktop и эмуляция размеров телефонов и планшетов.

## Проверенные размеры

320×760, 360×800, 390×844, 550×900, 699×1000, 700×1000, 768×1024, 899×1100, 900×1100, 1024×900, 1099×900, 1100×900, 1280×832, 1440×900, 1920×1080 и горизонтальный телефон 844×390.

Визуально просмотрены первый экран, «Обо мне», этапы работы, услуги, макеты портфолио, карточки и контакты. Дополнительно проверены загрузка шрифтов/изображений, меню, навигация по якорям и режим уменьшенной анимации.

## Исправленные дефекты

| Дефект | Исправление |
| --- | --- |
| «ПОРТФОЛИО» обрезалось на телефоне и накладывалось на иллюстрацию на планшете/ПК | Размер заголовка зависит от ширины его колонки; до 900 px используется вертикальная композиция, для горизонтального телефона — компактная строка |
| Google Fonts не загружался, системный шрифт изменял размеры текста | Oranienbaum поставляется локально, кириллица и латиница предварительно загружаются |
| Названия услуг заходили на описания | Переключение колонок перенесено на 900 px, размеры колонок и переносы согласованы |
| Длинные заголовки этапов выходили из карточек | Две колонки до 1440 px, четыре на широком экране; переносы и размер текста ограничены |
| Мелкий рукописный шрифт был труден для чтения | Основной шрифт используется в содержательных описаниях этапов, цитате и небольших акцентах «Обо мне» |
| Tailwind сужал контейнеры скачками между breakpoints | Единая максимальная ширина и плавные боковые отступы |
| Подписи инструментов пересекались на узком планшете | Промежуточная сетка из трёх колонок и ограниченный размер подписей |
| На мобильном портфолио не было видимого заголовка раздела | Добавлен «МОИ ПРОЕКТЫ»; desktop сохраняет вертикальные заголовки кейсов |
| Меню не помещалось на коротком горизонтальном экране | Внутренняя прокрутка, возврат фокуса по Escape и цикл Tab/Shift+Tab |
| Анимация могла сбрасывать повороты вертикальных заголовков | Перемещение, масштаб и вращение анимации используют отдельные CSS-свойства |
| Статический контент скрывался без JavaScript | Скрытие для анимации включается после гидратации; исходный HTML остаётся читаемым |
| Мобильные ссылки контактов выглядели как мелкие подписи к QR | Крупные строки ссылок с QR-кодами и SVG-стрелками |

## Повторные проверки

22 новых regression-тестов в `tests/e2e/responsive/layout.spec.ts` проверяют реальные прямоугольники текста, пересечения, выход за границы карточек и экрана, шрифты, меню и видимость статического HTML без JavaScript. Погрешность измерений — 3 px.

Итоговый общий прогон: **80 passed, 2 skipped**. Пропуски ожидаемы: тест открытия мобильного меню в desktop/tablet проектах. Статическая сборка и проверка типов прошли.

```sh
corepack pnpm run typecheck
corepack pnpm run build
corepack pnpm run test:e2e --workers=2
```

В облачной среде можно использовать установленный Chromium через `PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium`. При обычном локальном запуске используется браузер Playwright.

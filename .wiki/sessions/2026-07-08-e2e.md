## Lessons learned (на будущее)

- **Playwright + Nuxt 4 prerender** — webServer делает build перед запуском (медленно, но реалистично)
- **storageState** экономит время — не логинимся в каждом тесте
- **3 viewport в config** лучше чем `@ viewport` в каждом тесте — Playwright прогоняет все тесты для каждого проекта автоматически
- **data-testid уже есть** — спасибо прошлым рефакторингам, не пришлось добавлять
- **Slug-based IDs для тестов** — `case-test-mobile-app-fintech` стабильнее чем `case-case15`

### Lessons learned

- **minimax-coder для e2e** = правильный выбор (default tier, не premium). Справился за 1 заход
- **a11y-селекторы** (`getByRole`, `getByTestId`) стабильнее чем CSS — переживут рефакторинг
- **storageState pattern** экономит время — admin-setup запускается один раз
- **webServer production build** даёт более реалистичные тесты чем dev (prerender → реальный HTML)
- **Slug-based test-cases** — `case-test-mobile-app-fintech` стабильнее `case-99`
- **Portfolio CRUD test** работает через API (`/api/content?path=portfolio/{slug}`) потому что prerender статический

### Фикс warning Nuxt

После codex остался warning:
> `Two component files resolving to the same name PortfolioCaseLayout`
> (конфликт между `app/components/PortfolioCaseLayout.vue` и auto-import-именем `app/components/portfolio/CaseLayout.vue` → `PortfolioCaseLayout`)

**Решение оркестратора** (в этой же сессии, после codex):
1. Обнаружено, что `CaseLayout.vue` нигде не используется в `<template>` напрямую (только через import в `PortfolioCaseLayout.vue:24,31`)
2. Переименовал `CaseLayout.vue` → `CaseContent.vue`
3. Обновил 2 ссылки в `PortfolioCaseLayout.vue` (template + import)
4. Warning ушёл, typecheck зелёный

### Lessons learned

- **Codex предупреждал о warning** — оказался правильно, я пофиксил сам после него
- **Auto-import конфликты имён** в Nuxt при nested папках (`portfolio/CaseLayout.vue` → `PortfolioCaseLayout`) — нужно либо explicit imports, либо избегать имён которые префиксуются в название родительской папки
- **Baseline HTML diff** = идеальная верификация (контент-инварианты все сошлись)
- **«Грохай всё»** от пользователя = свобода для нормальных grid/flex layouts. В прошлой сессии codex боялся ломать визуал и сохранил legacy. Здесь — нет, и результат **в 4 раза меньше кода**
- **CSS Grid + clamp()** = правильный путь для админко-дружественного дизайна (контент может меняться, layout адаптируется)

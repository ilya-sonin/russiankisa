# cms-admin-pending

> **Статус**: ожидает обсуждения с заказчиком. Детали НЕ уточнены.

## Контекст

Заказчик сказал: «...нам надо будет настраивать и внедрять админку». Это единственное, что ясно.

## Что непонятно (нужно спросить)

1. **Что именно редактировать?**
   - Только кейсы портфолио (описание, изображения)?
   - Или контент всех секций (Hero, About, Services)?
   - Или «всё, что видит пользователь»?
2. **Кто будет редактировать?**
   - Только Екатерина?
   - Доверенные лица?
   - Публичный submit (от клиентов)?
3. **Где хостить?**
   - На том же сервере (Node + DB)?
   - Отдельный сервис (headless CMS)?
   - Local-first (markdown-файлы в git)?
4. **Auth нужна?**
   - Логин/пароль, OAuth, magic link?
   - 2FA?
5. **Нужен ли preview?**
   - Видеть изменения до публикации?
   - Или сразу в production?
6. **Версионирование?**
   - История изменений, откат?
7. **Workflow?**
   - Черновик → review → publish?
   - Или один статус «опубликовано»?

## Варианты (разбор)

### A. Headless CMS (Sanity / Strapi / Directus)

✅ Быстрый старт (1-2 дня)
✅ Готовый UI для редактирования
✅ Хороший preview
✅ API из коробки
❌ Vendor lock-in
❌ Нужно платить за SaaS (Sanity: $15+/мес)
❌ Self-hosted Strapi/Directus — отдельный контейнер + БД

### B. Nuxt Content (file-based, local-first)

✅ Бесплатно
✅ Markdown в git → версионирование
✅ Простой deploy (тот же Nuxt-контейнер)
❌ UI для редактирования — нет (правка в IDE/VSCode)
❌ Не для «обычного пользователя»

### C. Кастомный бэкенд (Nuxt server routes + SQLite/Postgres)

✅ Полный контроль
✅ Можно любой UI
✅ Self-contained
❌ Много кода (auth, CRUD, upload, preview)
❌ Нужно поддерживать

### D. Stagewise (visual editor)

⚠ Зависимость уже в `devDeps` — но **не подключена**.

✅ Прямо в браузере кликаешь на элементы → редактируешь
✅ Идеально для Екатерины (она сама дизайнер)
❌ Только для разработки/dev-сборки
❌ Не заменяет полноценный CMS

→ **Можно использовать в комбинации**: Stagewise для визуальной правки «по месту», CMS для контента.

### E. Designer-MCP (из ПКМ-Конструктор)

⚠ V1-only, не подходит для production-визитки.

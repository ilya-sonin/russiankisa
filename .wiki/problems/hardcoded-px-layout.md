# hardcoded-px-layout

## Проблема

Все секции (кроме `Header` и `Hero`) используют **absolute positioning с захардкоженными px-координатами** и фиксированную высоту `832px`.

## Где видно

```scss
.about {
  &__content { height: 832px; }
  &__title   { position: absolute; top: 240px; right: 0; }
  &__photo   { position: absolute; top: 249px; left: 640px; width: 468px; height: 335px; }
  &__tools   { position: absolute; top: 255px; left: 119px; width: 378px; }
  // ... 600+ строк таких координат
}
```

Все `PortfolioCaseN.vue` — `width: 1280px; height: 832px;`.

## Что ломается

| Ситуация | Что происходит |
|----------|----------------|
| Desktop 1920×1080 | 832px выглядит «коротко» относительно viewport |
| Desktop 2560×1440 | Ещё короче, элементы «кучкуются» в центре |
| Tablet 800px | absolute-координаты не масштабируются → наложения |
| Mobile 375px | Полная перестройка в column (но дизайн «ломается») |
| Browser zoom >100% | Элементы начинают пересекаться |
| Длинный текст в описании | `height: 832px` фиксирован → текст обрезается |
| Добавление нового кейса | Нужно подобрать координаты вручную |

## Где это боль

- **Любой текст > 85px высоты** в `.about__outro` → наезжает на footer
- **Любое изображение** с другим aspect ratio → не влезает в `width: 468px; height: 335px`
- **Landscape phone** (высота < 500px) → Hero не помещается

## Корневая причина

Скорее всего, при первой вёрстке **агент «копировал координаты из Figma-макета»** (1280×832) — это дало пиксель-перфект, но за счёт адаптивности.

## Решение (по приоритету)

### 1. Минимум (фиксы отдельных секций)

- Сделать `min-height: 832px` вместо `height: 832px` для секций с длинным текстом (Contact, About)
- Заменить `top: 240px` на `top: 30%` где возможно

### 2. Среднее (вынести в токены)

```scss
$about-layout-desktop: (
  title-top: 240px,
  photo-top: 249px,
  photo-left: 640px,
  photo-size: 468px 335px,
);
```

→ Менять в одном месте, но всё ещё absolute.

### 3. Кардинальное (CSS Grid)

```scss
.about {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-areas:
    "intro     photo"
    "title     photo"
    "tools     tools"
    "outro     outro";
  gap: 2rem;
}
```

→ Адаптивно, расширяемо, читаемо. НО требует переделки каждой секции.

## Рекомендация

**Прежде чем менять** — спросить заказчика: дизайн-макеты обновлены? Если макеты предполагают абсолютные координаты и на 1920, и на 1280 — решение 1. Если предполагают «резиновый» дизайн — решение 3.

**Для админки** — обязательно решение 3, иначе контент-менеджер не сможет менять длину текста.
